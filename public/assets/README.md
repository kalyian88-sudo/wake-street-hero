# /public/assets — GLB overrides

Every model in the game is procedural. To replace one with your own GLB, drop the file here and
map it in `manifest.json`:

```json
{
  "board.wakeboard": "my_board.glb",
  "winch": "winch.glb"
}
```

Keys are listed in the README (section "Подмена моделей на GLB").
